🌟 プロジェクト概要
本プロジェクトは、鈴木健太・めぐみ様ご夫妻のイタリア新婚旅行（HIS添乗員同行ツアー OI-KMI2811）を最高に楽しむために構築された、完全レスポンシブ（iPhone / スマートフォン最適化）対応の旅行ガイドポータルおよびインタラクティブWebシステムです。


YouTubeで大人気のイタリア公認ガイド・片庭みめさん（@mimeitalygaido）直伝のノウハウを凝縮した「初心者安心バイブル（beginner-guide.html）」、Leaflet.jsとOpenStreetMapを活用したGPS連動ルートマップ（tour-map.html）、日別の詳細スケジュール（day1.html〜day8.html）、食事マトリクス（ツアー設定食 vs 各自自由食）、都市別グルメ＆お土産ガイド、音楽・合唱愛好家向けのローマ教会散策ガイド、および動的Webアプリ（app.js: 持ち物チェックリスト+localStorage、リアルタイム為替・チップ計算機、音声つき指差しイタリア語会話ボード、SOS緊急モーダル）を統合しています。

🌐 GitHub Pages へのデプロイ手順
本サイトは静的HTML/CSS/JSおよびCSVファイルのみで構成されているため、GitHub PagesやNetlify、Vercel等へ即座に公開可能です。


1. 本リポジトリのルート（または site/ フォルダ）を GitHub リポジトリへプッシュします。
2. GitHub リポジトリの Settings > Pages を開きます。
3. Branch に main（または master）、フォルダに /root（または /site）を選択し、Save をクリックします。
4. 数分後、https://<username>.github.io/<repo-name>/ にてポータルサイトが公開されます。
5. iPhone / Android スマートフォンの Safari / Chrome で開き、「ホーム画面に追加」を行うことで、旅行中にアプリ感覚で素早くアクセスできます。
