## 🌟 プロジェクト概要

本プロジェクトは、鈴木健太・めぐみ様ご夫妻のイタリア新婚旅行（HIS添乗員同行ツアー OI-KMI2811）を最高に安心・快適・感動的に楽しむために構築された、完全レスポンシブ（iPhone / スマートフォン最適化）対応の旅行ガイドポータルおよびインタラクティブルートMAPシステムです。

## 🚀 主な機能と特徴

### 1. 🔰 初めてのイタリア旅行 完全安心バイブル (`beginner-guide.html`)
- **スリ対策 三種の神器**：首下げセキュリティポーチ、スマホ斜めがけストラップ、ダイヤル式南京錠の正しい活用法。
- **トイレ事情＆バール裏ワザ**：有料トイレ（€1.5）に並ばず、バールでエスプレッソを注文して綺麗なトイレを借りる裏ワザ。
- **バール＆レストランのマナー**：立ち飲み（Banco）と席（Tavolo）の料金差、席料（Coperto）とチップ（Mancia）の考え方。
- **教会見学のドレスコード**：肩・膝の露出厳禁対策（大判ストールの必携）。
- **スリ・詐欺の撃退法**：ミサンガ詐欺、ハトの餌、偽署名運動、地下鉄サンドイッチスリの具体的な対処法。
- **免税手続き（Tax Refund）**：2024年新基準（€70.01以上）と空港Otelloキオスク端末でのデジタル認証手順。

### 2. ⚡ 4大インタラクティブウィジェット (`app.js` & `index.html`)
1. **🧳 持ち物チェックリストウィジェット**：
   - 37項目の必須アイテムをカテゴリー別にフィルター。
   - `localStorage` 連動でチェック状態をブラウザに自動保存。
   - リアルタイム進捗バー表示（例: 「準備進捗: 15 / 37 項目 (41% 完了)」）。
2. **💶 ユーロ・円 ＆ 席料・チップ即時計算機**：
   - レート連動（デフォルト 1€ = 165円、変更可能）。
   - クイック設定ボタン（€1.5 カフェ、€5 ジェラート、€20 ランチ、€50 ディナー、€70.01 免税ライン）。
   - 人数・単価別の席料（Coperto）自動計算。
3. **🗣️ 必須イタリア語 指差しミニフレーズ（Web Speech API 音声再生）**：
   - 「Grazie mille」「Posso usare il bagno?」「Il conto, per favore」など15フレーズ。
   - スピーカーボタンを押すと、ブラウザ標準の音声合成でネイティブのイタリア語が再生されます。
4. **🚨 緊急SOS・大使館ワンタップ発信**：
   - 112（欧州総合緊急通報）、在イタリア日本国大使館（ローマ）、在ミラノ日本国総領事館へのワンタップ発信。
   - クレジットカード紛失時の緊急連絡先一覧モーダル。

### 3. 🗺️ インタラクティブルートMAP (`tour-map.html`)
- **Leaflet.js & OpenStreetMap** による高精度マップ表示（APIキー不要・軽量高速）。
- **全53箇所のカスタムピン**：
  - 🏛️ 観光スポット（Blue）
  - 🍽️ グルメ・食事（Red）
  - 🎁 お土産・買物（Purple）
  - 🏨 ホテル・拠点（Green）
  - ⚠️ 治安・注意ポイント（Orange/Red Pulse：テルミニ駅、コロッセオ、リアルト橋、ドゥオーモ前等）
  - 🔰 初心者スポット（Yellow：イータリー、サンテウスタキオ等）
- **カテゴリ絞り込み・日程絞り込み・リアルタイムテキスト検索**。
- **リッチポップアップカード**：日本語名・イタリア語名、カテゴリバッジ、日程タグ、予約要否、みめTip、Google Maps直接リンク、詳細ページリンク。

### 4. 📊 構造化CSVデータ
- **`itinerary.csv`**：全8日間の日程・都市・交通・食事条件・見どころ・**みめ直伝アドバイス（`mime_guide_tips`）**・リンク。
- **`spots.csv`**：全53スポットの座標・日伊名称・カテゴリ・予約要否・**みめTip（`mime_tip`）**・Google Mapsリンク。
- **`packing_list.csv`**：40+項目の持ち物データ・カテゴリ・重要度・**みめ推奨理由（`mime_recommendation`）**。

## 🌐 GitHub Pages へのデプロイ手順

本サイトは静的HTML/CSS/JSおよびCSVファイルのみで構成されているため、GitHub Pages等へ即座に公開可能です。

1. 本リポジトリのルートを GitHub リポジトリへプッシュします。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Branch** に `main`（または `master`）、フォルダに `/root`（または `/site`）を選択し、**Save** をクリックします。
4. 数分後、`https://<username>.github.io/<repo-name>/` にてポータルサイトが公開されます。
5. iPhone / Android スマートフォンの Safari / Chrome で開き、「ホーム画面に追加」を行うことで、旅行中にアプリ感覚で素早くアクセスできます。
