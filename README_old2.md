## 🚀 主な機能と追加ページ詳細

### 1. 🎁 お土産＆ショッピング完全ガイド 45選 (`souvenir-guide.html`)
- **7都市特産名物 ＆ 定番ギフト**：
  - ミラノ：老舗パネットーネ（G.Cova & C.）、リナシェンテ限定スイーツ、Venchi / Caffarel チョコ。
  - ベローナ：パンドーロ（Bauli/Melegatti）、ジュリエットのハートクッキー（Baci di Giulietta）、アマローネ赤ワイン。
  - ベネチア：ムラーノガラス（ミルフィオリペンダント・正規公認シール確認法）、ブラーノ島レース、スプリッツセット。
  - フィレンツェ：サンタ・マリア・ノヴェッラ世界最古薬局（香水『王妃の水』、ザクロ石鹸、ローズウォーター、ポプリ）、トスカーナ本革製品（シームレスコインケース、手袋）、イル・パピロのマーブル紙文房具、白トリュフ塩＆オイル、カントゥッチ＆ヴィンサント。
  - ピサ：斜塔ミニチュア、トスカーナ産オリーブウッドのカッティングボード。
  - サンジミニャーノ：D.O.P.サフラン、ヴェルナッチャ・ディ・サンジミニャーノ白ワイン。
  - ローマ：サンテウスタキオ・イル・カッフェの豆＆チョコがけ豆（Chococafe）、タッツァ・ドーロ、カストローニの輸入高級食材、リモンチェッロ。
  - バチカン：公式ロザリオ、奇跡のメダイ、歴代教皇記念コイン。
- **スーパー（Conad, Coop, Esselunga）で買える神コスパばらまき土産**：
  - Baciチョコ、冬季限定ポケットコーヒー（液状エスプレッソ入り）、Noviチョコ、Grisbìクッキー（ピスタチオ/レモン）、Rummo特殊パスタ、乾燥ポルチーニ茸、Mutti濃縮トマトペースト、24ヶ月熟成パルミジャーノ・レッジャーノ真空パック、MARVIS歯磨き粉、KIKO Milanoコスメ。
- **2024年法改正対応 免税（Tax Refund）シミュレーター**：最低購入額 €70.01 に連動したリアルタイム還付額（約12.5%）計算。
- **税関・検疫・液体物パッキングルール**：肉製品（生ハム等）の持込禁止警告（最高300万円罰金）、ハードチーズ持込可能案内、液体物スーツケース預け入れルール。

### 2. 💡 イタリアあるある・歴史文化・最新トレンド (`culture-trends.html`)
- **ネット口コミ500件分析！イタリアあるある 30選**：
  - 交通編：電車の発車直前ホーム変更、打刻忘れ€50罰金、金曜ストライキ、石畳でキャスター悲鳴。
  - 飲食編：バールの立ち飲み（Banco）vs 着席（Tavolo）の価格差、11時以降カプチーノ頼むと怪訝な顔、パスタのスプーン禁止、ピザ1人1枚丸ごと、会計が全然来ない、ガス入り水（Frizzante）問題。
  - ホテル・生活編：便座のないトイレ、謎の陶器ビデ（Bidet）、アメニティ皆無、シャワー激狭、シエスタ（Riposo）閉店、レシート所持義務。
  - 治安編：ミサンガ詐欺撃退法、テーブル上スマホ3秒盗難、教会の肩・膝露出禁止。
- **歴史と地域文化（カンパニリズモ＝我が町一番）**：
  - 1861年統一の背景と、ミラノ（洗練・バター）・ベネチア（海洋・魚介）・トスカーナ（ルネサンス・肉とオイル）・ローマ（古代帝国・下町パスタ）の食と気質の徹底比較。
- **今イタリアで大流行中！最新トレンド（日本の二郎系に相当する現地の熱狂）**：
  - ① **ピンサ・ロマーナ (Pinsa Romana)**：古代ローマ発祥、72時間長時間発酵で外カリ中ふわ＆低糖質ヘルシーピザの爆発的ブーム。
  - ② **スップリ ＆ トラピッツィーノ (Trapizzino)**：カルボナーラ味スップリや、煮込み料理を詰めた三角ピザポケットのストリートフード革命。
  - ③ **ピスタチオ・マニア (Pistacchio Mania)**：シチリア・ブロンテ産ピスタチオを使った朝食コルネット、ティラミス、ピザの全国的ブーム。
  - ④ **スペシャルティコーヒー ＆ サードウェーブカフェ**：浅煎りシングルオリジンやハンドドリップを提供する新世代カフェ。
  - ⑤ **スプリッツ・ウーゴ (Spritz Hugo)**：エルダーフラワーリキュールとプロセッコの爽快カクテル。
  - ⑥ **進化系パティスリー**：お食事系塩味マリトッツォ（サレ）やカスタムカンノーリ。
- **失敗談ワースト5と回避策ランキング**。

### 3. 🚆 交通・通信・ホテル・緊急サバイバル完全攻略 (`tips-survival.html`)
- **交通サバイバル**：
  - 地下鉄のクレカタッチ乗車「Tap & Go」（切符売り場に並ばずApple Pay/クレカで即改札通過）。
  - 普通列車（Regionale）の乗車前刻印（Timbrare）ルール。
  - 市バス・トラムのタバッキ事前購入＆車内打刻。
  - ストライキ（Sciopero）の最低保証時間帯（Fasce di Garanzia）とツアー時の影響。
  - タクシーの乗り方、白タク見分け方、空港定額運賃（FCO〜ローマ市内 €55）。
- **通信・スマホ・決済・両替**：
  - eSIM（Airalo等）の出国前・到着後設定とトラブルシューティング。
  - クレジットカード決済・暗証番号PIN確認・タッチ決済活用。
  - **ATMキャッシングのDCC手数料トラップ回避法（必ず「Without Conversion / EUR建て」を選択！）**。
  - モバイルバッテリー機内持ち込みルール（スーツケース預け厳禁）。
- **ホテル・滞在生活**：
  - アメニティ不足対策（スリッパ・歯ブラシ・パジャマ・ケトル持参）。
  - 水道水・硬水対策・ミネラルウォーター選び（Naturale vs Frizzante）。
  - 宿泊税（Tassa di Soggiorno）の支払い。
- **健康・薬局・緊急SOS**：
  - 街の薬局（Farmacia）で買える市販薬（Tachipirina, Enterogermina等）と症状別イタリア語。
  - 欧州総合緊急通報 **112** ワンタップ発信。
  - 在イタリア日本国大使館（ローマ）・在ミラノ総領事館連絡先。
  - パスポート紛失時の「帰国のための渡航書」申請手順。
  - クレジットカード緊急紛失デスク一覧モーダル。
- **ハネムーン写真撮影Tips**：安全なツーショットの頼み方（「Ci peut fare una foto, per favore?」）とベスト撮影時間帯。

## 🌐 GitHub Pages へのデプロイ手順
1. 本リポジトリの全ファイルを GitHub リポジトリへプッシュします。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Branch** に `main`（または `master`）、フォルダに `/root` を選択し、**Save** をクリックします。
4. 数分後、`https://<username>.github.io/<repo-name>/` にてポータルサイトが公開されます。
5. iPhone の Safari で開き、「共有」>「ホーム画面に追加」を行うことで、旅行中にアプリ感覚で素早くアクセスできます。
