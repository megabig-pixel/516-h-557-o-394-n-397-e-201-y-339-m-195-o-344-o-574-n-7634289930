## 🌐 GitHub Pages へのデプロイ手順
1. 本リポジトリの全ファイルを GitHub リポジトリへプッシュします。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Branch** に `main`（または `master`）、フォルダに `/root` を選択し、**Save** をクリックします。
4. 数分後、`https://<username>.github.io/<repo-name>/` にてポータルサイトが公開されます。
5. iPhone の Safari で開き、「共有」>「ホーム画面に追加」を行うことで、旅行中にアプリ感覚で素早くアクセスできます。
